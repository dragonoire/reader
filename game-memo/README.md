# 游戏活动备忘录

纯前端网页 App（单个 HTML，无需构建），数据保存在浏览器本地。

- **今日**：今天是开服第几天、正在进行的活动（剩余天数/进度）、即将开始的活动
- **日历**：按月查看每天有哪些活动，点日期看详情、直接在这天添加
- **活动**：按「开服天数」或「具体日期」记录活动；改开服日期后自动换算；支持批量粘贴表格
- **攻略**：保存攻略笔记，`A 合作 B` 自动排成对照表，`#` 开头为小标题，可搜索
- **设置**：多个游戏/区服、开服日期、备份导出与恢复、深浅色

## 使用

直接用浏览器打开 `index.html` 即可。部署到任意静态托管（如 GitHub Pages）后，
手机浏览器里「添加到主屏幕」就能像 App 一样离线使用。
